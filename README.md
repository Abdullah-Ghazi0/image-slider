# Image Slider

A smooth, infinite scrolling image slider built with vanilla JavaScript.

## Feature
- Infinite looping (seamless scroll)
- Smooth CSS transitions
- Navigation buttons (prev/next)
- Slide indicator controls
- Auto-play functionality
- Basic edge-case handling


## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)

## About

This is a learning project built to understand how image sliders and carousels work under the hood, especially:

- Infinite looping logic
- Animation handling
- State management

## Note

This project is not production-ready and does not fully follow industry best practices.  <br>
It was created purely for learning and experimentation.
